## Как я работаю

- **Разбираюсь в новом сам.** Каждая технология в этих проектах — та, которой я не знал до начала работы.
- **AI — ускоритель, а не замена.** Ставлю задачу, читаю сгенерированный код, проверяю тестами и могу объяснить каждую строку; непонятное переписываю.
- **Критерий готовности — работает и воспроизводится.** Тест на новую логику, запуск в Docker, а не только в IDE; проект должен подниматься одной командой у другого человека.
- **Решения фиксирую с причиной и альтернативой.** В README каждого проекта есть раздел «Принятые решения».
- **Не прячу слабые места.** В GameChat отдельным разделом перечислено, что сделано неправильно (SQL-конкатенация, пароли в открытом виде), и как это исправлено в следующих проектах — по этой разнице видно рост.
- **Довожу до конца.** Каждый проект дописан до состояния, в котором его можно открыть, запустить и проверить: README, скриншоты, инструкция по запуску, демо-данные.
