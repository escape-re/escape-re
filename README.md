Делаю проекты, в которых закрываю весь путь backend-задачи: от схемы БД и API-контракта до кэша, тестов и запуска в контейнерах. ## Немного о себе

Выпускник специальности «Информационные системы и программирование» (СПО, 2025). Дипломный проект — клиент-серверный мессенджер на WCF — защищён на отлично и занял 2-е место на курсе.

После службы в армии вернулся к программированию: восстановил базу C#, сделал первый пет-проект на Dapper, затем перешёл к тому, чем хочу заниматься профессионально, — backend-разработке на ASP.NET Core. Сейчас основной фокус — EF Core, проектирование API и качество кода: тесты, обработка ошибок, конфигурация и контейнеризация.

Ищу позицию **Junior C# Backend Developer** с возможностью удалённой работы и готов начать сразу. Больше всего интересует проектирование API и работа с данными — схемы БД, запросы, кэширование.
